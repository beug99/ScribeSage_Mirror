# ✍️ ScribeSage – AI-Enhanced Note-Taking App for Students

ScribeSage is a JavaFX-based desktop word processor tailored for students, integrating AI-powered enhancements and transcription tools. Built by a 5-person team as a university capstone project, it helps students organize, summarize, and manage notes with ease.

---

## 💡 Features

- 📝 Create, edit, and organize notes into folders  
- 🧠 AI note enhancement using OpenAI o4-mini  
- 🎙️ Audio transcription using Vosk  
- 🔍 In-document search (Ctrl+F) and document-wide search  
- 🔐 User authentication and profile management  
- 📤 Export notes to PDF  
- 📁 Canvas integration (text, image, audio import)

---

## 🧪 Tech Stack

- **Language**: Java 17 (Amazon Corretto)  
- **UI Framework**: JavaFX  
- **AI & Speech**: OpenAI o4-mini, Vosk  
- **Database**: SQLite (separate DBs for users and notes)  
- **Testing & CI**: JUnit5, Maven, GitHub Actions  
- **IDE**: IntelliJ IDEA
